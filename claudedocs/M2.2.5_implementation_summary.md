## 2. 구현 세부사항

### 2.1 핵심 함수 구현

#### 2.1.1 통합 계산 함수
```javascript
calculateCapitalGainsTax(params)
```

**입력 파라미터**:
```typescript
{
  acquisitionDate: string,      // 취득일 (YYYY-MM-DD)
  acquisitionPrice: number,     // 취득가액
  transferDate: string,         // 양도일 (YYYY-MM-DD)
  transferPrice: number,        // 양도가액
  houseCount: 1 | 2 | 3,       // 주택 수
  address: string,              // 주소 (조정대상지역 판정)
  necessaryExpenses?: number,   // 필요경비 (선택)
  residenceYears?: number,      // 거주년수 (선택)
  tempDual2Years?: boolean      // 일시적 2주택 (선택)
}
```

**출력 구조**:
```typescript
{
  // 계산 과정
  holdingPeriod: { years, days, months },
  capitalGain: number,

  exemption: {
    applied: boolean,
    amount: number,
    reason: string
  },

  longTermDeduction: {
    rate: number,
    amount: number,
    totalYears: number
  },

  basicDeduction: number,
  taxBase: number,

  taxation: {
    basicRate: number,
    basicTax: number,
    surchargeApplied: boolean,
    surchargeRate: number,
    totalRate: number,
    capitalGainsTax: number
  },

  localIncomeTax: number,
  totalTax: number,

  // 메타 정보
  calculationDate: string,
  warnings: string[],
  isRegulated: boolean,
  effectiveRate: number
}
```
