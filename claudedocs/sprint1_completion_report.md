## 🔍 데이터 검증 결과

### 상속세 세율 검증
```javascript
// 테스트 케이스 1: 과세표준 5억원
상속세 = 5억 × 20% - 1천만원 = 9천만원 ✅

// 테스트 케이스 2: 과세표준 15억원
상속세 = 15억 × 40% - 1.6억 = 4.4억원 ✅

// 테스트 케이스 3: 과세표준 50억원
상속세 = 50억 × 50% - 4.6억 = 20.4억원 ✅
```

### 증여세 세율 검증
```javascript
// 상속세와 동일한 세율 적용 확인
증여세(5억) = 상속세(5억) = 9천만원 ✅
```

### 상속세 공제 검증
```javascript
// 시나리오: 상속재산 10억, 배우자+자녀 2명
기초공제 = 2억원 ✅
배우자공제 = max(5억, 10억×30%) = 5억원 ✅
자녀공제 = 2명 × 5천만원 = 1억원 ✅
개별공제 합계 = 8억원
일괄공제 = 5억원
→ 선택: 개별공제 8억원 (더 유리) ✅
```

### 증여세 공제 검증
```javascript
// 시나리오: 부모→성년 자녀 1억원 증여
관계: 직계존속(성년)
공제액 = 5천만원 ✅
과세표준 = 1억 - 5천만원 = 5천만원 ✅
```
