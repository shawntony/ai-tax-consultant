# Phase 5: 엔드투엔드 테스트 가이드

## 서버 상태 확인

✅ React 개발 서버: http://localhost:3000 - 실행 중
✅ Express 백엔드 서버: http://localhost:3001 - 실행 중
✅ 컴파일: 성공

## 테스트 시나리오

### 시나리오 1: 전체 워크플로우 테스트

#### Step 1: 초기 화면
1. 브라우저에서 http://localhost:3000 접속
2. 홈 화면에서 "세무 최적화 워크플로우" 클릭
3. ✅ 확인사항:
   - 케이스 설명 입력 필드 표시
   - 3개의 예시 케이스 버튼 표시
   - 사이드바 표시/숨기기 버튼 작동

#### Step 2: 케이스 입력 및 대화형 정보 수집
1. 예시 케이스 중 "증여 vs 상속" 클릭
2. "분석 시작" 버튼 클릭
3. ✅ 확인사항:
   - ConversationFlow 화면으로 전환
   - 5개 카테고리 탭 표시
   - 진행률 바 표시
   - 질문별 입력 필드 작동

4. 각 카테고리별 정보 입력:
   - **기본 정보**: 증여 vs 상속 선택, 증여자/수증자 관계 선택
   - **부동산 현황**: 부동산 시가 1,000,000,000원 입력
   - **가족 관계**: 자녀 수, 배우자 상태 입력
   - **자산 현황**: 기타 자산 정보 입력
   - **목적 및 제약**: 목적 및 우선순위 입력

5. "완료" 버튼 클릭
6. ✅ 확인사항:
   - 완성도가 80% 이상인지 확인
   - "분석 시작" 버튼 활성화

#### Step 3: AI 분석 단계
1. "분석 시작" 버튼 클릭
2. ✅ 확인사항:
   - 로딩 스피너 표시
   - "AI가 전략을 분석하고 있습니다" 메시지 표시
   - 진행 단계 표시:
     - ✓ 정보 수집 완료
     - 🔄 시나리오 생성 중
     - ⏳ 세금 계산 대기 중
     - ⏳ 전략 비교 대기 중

3. 백엔드 API 호출 확인 (콘솔 체크)
4. ✅ 확인사항:
   - `/api/generate-strategy` 호출 성공
   - 응답 시간 < 30초
   - 에러 없이 완료

#### Step 4: 노드 그래프 시각화
1. 분석 완료 후 자동으로 노드 화면으로 전환
2. ✅ 확인사항:
   - 좌측 사이드바: 수집된 정보 요약 표시
   - 중앙: SimpleNodeFlow 그래프 표시
   - 우측 사이드바: 전략 성과 통계 표시
   - 5개 시각화 버튼 표시

#### Step 5: 시나리오 비교표
1. 우측 사이드바에서 "📊 시나리오 비교표" 버튼 클릭
2. ✅ 확인사항:
   - StrategyComparison 컴포넌트 표시
   - 비교 테이블 렌더링
   - 정렬 기능 작동 (컬럼 헤더 클릭)
   - 추천 시나리오 하이라이트
   - 상세 분석 카드 표시 (pros, cons, risks)
   - 복잡도 배지 표시

3. 테스트 액션:
   - 각 컬럼 헤더 클릭하여 정렬 테스트
   - 정렬 아이콘 변경 확인 (↑ ↓)
   - 상세 분석 카드 스크롤 테스트

#### Step 6: 의사결정 트리
1. "🌳 의사결정 트리" 버튼 클릭
2. ✅ 확인사항:
   - DecisionTree 컴포넌트 표시
   - ReactFlow 그래프 렌더링
   - 루트 노드 → 시나리오 노드 구조
   - MiniMap 표시
   - Controls 버튼 작동

3. 테스트 액션:
   - 줌 인/아웃 테스트
   - 팬 (드래그) 테스트
   - MiniMap 클릭 네비게이션
   - 노드 클릭 (콘솔에 로그 확인)

#### Step 7: 실행 계획서
1. "📋 실행 계획서" 버튼 클릭
2. ✅ 확인사항:
   - ActionPlan 컴포넌트 표시
   - 타임라인 마커 표시
   - 전체 주의사항 표시
   - 추천 전략 배너 표시

3. 테스트 액션:
   - 각 단계 클릭하여 확장/축소
   - 필요 서류 목록 확인
   - 체크리스트 체크박스 클릭
   - 비용 상세 확인

#### Step 8: 세금 시뮬레이터
1. "💰 세금 시뮬레이션" 버튼 클릭
2. ✅ 확인사항:
   - TaxSimulator 컴포넌트 표시
   - 3개 탭 표시 (증여세, 상속세, 부담부증여 최적화)
   - 파라미터 조정 슬라이더 작동
   - 실시간 계산 결과 업데이트

3. 테스트 액션:
   - 각 탭 전환 테스트
   - 슬라이더로 부동산 시가 조정
   - 계산 결과 실시간 업데이트 확인
   - 부담부증여 최적화 시나리오 비교 테이블 확인

#### Step 9: 정보 수정 테스트
1. 좌측 사이드바에서 "✏️ 수정" 버튼 클릭
2. ✅ 확인사항:
   - ConversationFlow 화면으로 돌아감
   - 이전 입력 값 유지됨
   - 수정 후 다시 분석 가능

#### Step 10: 사이드바 토글
1. 상단 헤더에서 사이드바 토글 버튼 클릭
2. ✅ 확인사항:
   - 좌측 사이드바 숨기기/표시 작동
   - 중앙 컨텐츠 영역 크기 자동 조정
