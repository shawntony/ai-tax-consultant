## 2. 비과세 요건 (2024년 기준)

### 2.1 기본 요건 (필수 3가지)

#### 2.1.1 1세대 판정
**정의**: 거주자 및 그 배우자가 그들과 동일한 주소 또는 거소에서 생계를 같이하는 가족과 함께 구성하는 1세대

**판정 기준**:
- ✅ **1세대**: 본인, 배우자, 생계를 같이하는 가족
- ❌ **별도 세대**: 결혼한 자녀는 별도 세대로 인정

**구현**:
```javascript
// 현재 MVP에서는 사용자 입력에 의존
// Phase 5 (DB 구축 후) 가족관계 DB로 자동 판정
function is1세대(userId) {
  // 향후 구현: 가족 관계 DB 조회
  // 현재는 사용자가 "1세대1주택" 선택 시 true
  return true;
}
```

#### 2.1.2 1주택 판정
**정의**: 1세대가 국내에 1개의 주택만 보유

**판정 기준**:
- ✅ **1주택**: 국내 주택 1채만 보유
- ⚠️ **주의**: 양도 당시 기준 (양도 후에는 0주택)
- ❌ **2주택 이상**: 비과세 불가

**예외 (일시적 2주택):**
- 이사를 위해 신규 주택 취득 후 2년 이내 종전 주택 양도
- 상속 주택 + 일반 주택 (상속 주택 5년 이내 양도)

**구현**:
```javascript
function is1주택(houseCount, tempDual2Years = false) {
  if (houseCount === 1) return true;
  if (houseCount === 2 && tempDual2Years) return true; // 일시적 2주택
  return false;
}
```

#### 2.1.3 보유기간 요건
**요건**: 양도일 현재 2년 이상 보유

**계산**:
```javascript
function 보유기간Check(acquisitionDate, transferDate) {
  const diffDays = (new Date(transferDate) - new Date(acquisitionDate)) / (1000 * 60 * 60 * 24);
  const holdingYears = diffDays / 365;
  return holdingYears >= 2; // 2년 이상
}
```

**특례**:
- 조정대상지역 내 주택: 2년 이상 보유 + 2년 이상 거주 필요 (2021년 이후)
- 비조정대상지역: 보유 2년만 충족하면 OK

### 2.2 거주 요건 (조정대상지역)

#### 2.2.1 조정대상지역이란?
**정의**: 주택 가격 급등 우려가 있는 지역 (국토교통부 지정)

**2024년 현재 주요 조정대상지역**:
- 서울 전역 (25개 자치구)
- 경기 과천시, 성남시 분당구, 하남시
- 기타 일부 지역

**구현**:
```javascript
// 조정대상지역 목록 (DB 또는 Constants)
const REGULATED_AREAS = [
  '서울특별시',
  '경기도 과천시',
  '경기도 성남시 분당구',
  '경기도 하남시'
  // ... 추가 지역
];

function isRegulatedArea(address) {
  return REGULATED_AREAS.some(area => address.startsWith(area));
}
```

#### 2.2.2 거주 요건 (조정대상지역 주택)
**요건 (2021.1.1 이후 취득분)**:
- 보유기간 2년 이상 **AND**
- 거주기간 2년 이상

**거주기간 계산**:
- 실제 거주한 기간의 합계
- 연속이 아니어도 됨 (합산 2년)

```javascript
function 거주요건Check(isRegulated, acquisitionDate, residenceYears, holdingYears) {
  // 2021년 이전 취득 → 거주 요건 없음
  if (new Date(acquisitionDate) < new Date('2021-01-01')) {
    return true;
  }

  // 조정대상지역이 아님 → 거주 요건 없음
  if (!isRegulated) {
    return true;
  }

  // 조정대상지역 + 2021년 이후 취득 → 보유 2년 + 거주 2년
  return holdingYears >= 2 && residenceYears >= 2;
}
```

### 2.3 양도가액 기준 (고가주택)

#### 2.3.1 12억원 기준
**규정**:
- 양도가액 12억원 이하: 전액 비과세
- 양도가액 12억원 초과: 12억 초과분에 대해 과세

**계산 공식**:
```javascript
function calculate비과세금액(transferPrice, capitalGain) {
  if (transferPrice <= 1200000000) {
    // 12억 이하 → 전액 비과세
    return {
      exemptAmount: capitalGain,
      taxableAmount: 0,
      exemptRatio: 1.0
    };
  } else {
    // 12억 초과 → 비율 계산
    const exemptRatio = 1200000000 / transferPrice;
    const exemptAmount = Math.floor(capitalGain * exemptRatio);
    const taxableAmount = capitalGain - exemptAmount;

    return {
      exemptAmount,
      taxableAmount,
      exemptRatio
    };
  }
}
```

**예시**:
```
양도가액: 15억원
취득가액: 10억원
양도차익: 5억원

비과세 비율 = 12억 / 15억 = 0.8 (80%)
비과세 금액 = 5억 × 0.8 = 4억원
과세 대상 = 5억 - 4억 = 1억원
```

## 4. 통합 함수 구현

### 4.1 메인 비과세 판단 함수
```javascript
/**
 * 1세대1주택 비과세 판단 및 계산
 * @param {Object} params
 * @returns {Object} 비과세 판단 결과
 */
function check1House1HouseholdExemption(params) {
  const {
    houseCount,             // 주택 수 (1, 2, 3+)
    tempDual2Years,         // 일시적 2주택 여부
    holdingYears,           // 보유기간 (년)
    isRegulatedArea,        // 조정대상지역 여부
    acquisitionDate,        // 취득일
    residenceYears,         // 거주기간 (년)
    transferPrice,          // 양도가액
    capitalGain             // 양도차익
  } = params;

  // Step 1: 1주택 여부 확인
  if (!is1주택(houseCount, tempDual2Years)) {
    return {
      exempt: false,
      exemptAmount: 0,
      taxableGain: capitalGain,
      reason: '1세대1주택이 아님 (현재 주택 수: ' + houseCount + '개)',
      details: {
        step: 1,
        stepName: '1주택 판정',
        passed: false
      }
    };
  }

  // Step 2: 보유기간 확인
  if (holdingYears < 2) {
    return {
      exempt: false,
      exemptAmount: 0,
      taxableGain: capitalGain,
      reason: '보유기간 2년 미만 (현재: ' + holdingYears.toFixed(1) + '년)',
      details: {
        step: 2,
        stepName: '보유기간 판정',
        passed: false,
        requiredYears: 2,
        actualYears: holdingYears
      }
    };
  }

  // Step 3 & 4: 거주요건 확인 (조정대상지역 + 2021년 이후)
  const acquisition2021OrLater = new Date(acquisitionDate) >= new Date('2021-01-01');

  if (isRegulatedArea && acquisition2021OrLater) {
    if (residenceYears < 2) {
      return {
        exempt: false,
        exemptAmount: 0,
        taxableGain: capitalGain,
        reason: '조정대상지역 거주기간 2년 미만 (현재: ' + (residenceYears || 0).toFixed(1) + '년)',
        details: {
          step: 4,
          stepName: '거주기간 판정',
          passed: false,
          requiredYears: 2,
          actualYears: residenceYears || 0,
          isRegulatedArea,
          acquisition2021OrLater
        }
      };
    }
  }

  // Step 5: 양도가액 기준 확인
  const { exemptAmount, taxableAmount, exemptRatio } = calculate비과세금액(transferPrice, capitalGain);

  // 결과 반환
  if (taxableAmount === 0) {
    // 전액 비과세
    return {
      exempt: true,
      fullExempt: true,
      exemptAmount,
      taxableGain: 0,
      exemptRatio,
      reason: '1세대1주택 비과세 (양도가액 12억 이하)',
      details: {
        step: 5,
        stepName: '양도가액 판정',
        passed: true,
        transferPrice,
        threshold: 1200000000,
        over12B: false
      }
    };
  } else {
    // 부분 비과세 (12억 초과)
    return {
      exempt: false,
      partialExempt: true,
      exemptAmount,
      taxableGain: taxableAmount,
      exemptRatio,
      reason: '1세대1주택 부분 비과세 (양도가액 12억 초과)',
      details: {
        step: 5,
        stepName: '양도가액 판정',
        passed: true,
        transferPrice,
        threshold: 1200000000,
        over12B: true,
        exemptPortion: (exemptRatio * 100).toFixed(1) + '%',
        taxablePortion: ((1 - exemptRatio) * 100).toFixed(1) + '%'
      }
    };
  }
}
```
