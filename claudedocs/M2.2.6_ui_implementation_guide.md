## 주요 기능

### 1. 실시간 보유기간 계산
**구현**: `useEffect` 훅을 사용한 자동 계산

```javascript
useEffect(() => {
  if (formData.acquisitionDate && formData.transferDate) {
    const acqDate = new Date(formData.acquisitionDate);
    const transDate = new Date(formData.transferDate);

    if (transDate >= acqDate) {
      const diffInDays = Math.floor((transDate - acqDate) / (1000 * 60 * 60 * 24));
      const years = Math.floor(diffInDays / 365);
      const months = Math.floor((diffInDays % 365) / 30);

      setHoldingPeriod({ years, months, days: diffInDays });
    } else {
      setHoldingPeriod(null);
    }
  }
}, [formData.acquisitionDate, formData.transferDate]);
```

**사용자 경험**:
- 취득일과 양도일 입력 시 즉시 보유기간 표시
- "3년 5개월" 형태로 가독성 높은 표시
- 날짜 유효성 검증 (양도일 ≥ 취득일)

### 2. 숫자 포맷팅
**구현**: 천 단위 구분 기호 자동 삽입

```javascript
const formatNumber = (value) => {
  if (!value) return '';
  const number = value.toString().replace(/,/g, '');
  return number.replace(/\B(?=(\d{3})+(?!\d))/g, ',');
};

const parseNumber = (value) => {
  return parseInt(value.replace(/,/g, '')) || 0;
};
```

**사용자 경험**:
- 입력 시: "1000000000" → 표시: "1,000,000,000"
- 계산 시: 자동으로 숫자로 변환
- 단위 표시: "원" (KRW)

### 3. 폼 유효성 검증
**구현**: `validateForm()` 함수로 모든 필수 입력 검증

```javascript
const validateForm = () => {
  const newErrors = {};

  // 필수 필드 검증
  if (!formData.acquisitionDate) {
    newErrors.acquisitionDate = '취득일을 입력해주세요';
  }
  if (!formData.acquisitionPrice) {
    newErrors.acquisitionPrice = '취득가액을 입력해주세요';
  }
  if (!formData.transferDate) {
    newErrors.transferDate = '양도일을 입력해주세요';
  }
  if (!formData.transferPrice) {
    newErrors.transferPrice = '양도가액을 입력해주세요';
  }

  // 날짜 논리 검증
  if (formData.acquisitionDate && formData.transferDate) {
    if (new Date(formData.transferDate) < new Date(formData.acquisitionDate)) {
      newErrors.transferDate = '양도일은 취득일 이후여야 합니다';
    }
  }

  setErrors(newErrors);
  return Object.keys(newErrors).length === 0;
};
```

**에러 메시지 표시**:
- 각 입력 필드 하단에 빨간색 에러 메시지
- 입력 필드 테두리 색상 변경 (빨간색)
- 제출 시 첫 번째 에러 필드로 포커스 이동

### 4. 조건부 렌더링

```javascript
const [formData, setFormData] = useState({

  transferPrice: '',        // 양도가액 (string for formatting)

  // 주택 정보
  houseCount: 1,           // 주택 수 (1, 2, 3)
  address: '',             // 주택 소재지
  residenceYears: '',      // 거주기간 (1주택만)
  tempDual2Years: false    // 일시적 2주택 여부 (2주택만)
});

const [result, setResult] = useState(null);           // 계산 결과
const [showResults, setShowResults] = useState(false); // 결과 표시 여부
const [holdingPeriod, setHoldingPeriod] = useState(null); // 보유기간
const [errors, setErrors] = useState({});             // 유효성 검증 에러
```

### State 업데이트 패턴
```javascript
// 통합 입력 핸들러
const handleInputChange = (e) => {
  const { name, value, type, checked } = e.target;

  setFormData(prev => ({
    ...prev,
    [name]: type === 'checkbox' ? checked :
            type === 'radio' ? parseInt(value) :
            value
  }));

  // 에러 클리어
  if (errors[name]) {
    setErrors(prev => {
      const newErrors = { ...prev };
      delete newErrors[name];
      return newErrors;
    });
  }
};
```

## 사용자 인터랙션 플로우

### 1. 기본 입력 플로우
```
1. 사용자가 취득일 입력
   ↓
2. 사용자가 양도일 입력
   ↓
3. 보유기간 자동 계산 및 표시 (useEffect)
   ↓
4. 취득가액/양도가액 입력
   - 입력 시 천 단위 구분 기호 자동 삽입
   ↓
5. 주택 수 선택 (라디오 버튼)
   - 1주택 → 거주기간 입력 필드 표시
   - 2주택 → 일시적 2주택 체크박스 표시
   - 3주택 이상 → 추가 입력 없음
   ↓
6. 주택 소재지 입력 (조정대상지역 판단용)
```

### 2. 계산 플로우
```
1. "계산하기" 버튼 클릭
   ↓
2. validateForm() 실행
   - 필수 필드 검증
   - 날짜 논리 검증
   ↓
3. 유효성 검증 실패 시
   - 에러 메시지 표시
   - 첫 번째 에러 필드로 포커스
   - 계산 중단
   ↓
4. 유효성 검증 성공 시
   - calculateCapitalGainsTax() 호출
   - 결과를 result state에 저장
   - showResults를 true로 설정
   ↓
5. 결과 섹션 애니메이션과 함께 표시
   - 비과세 → 성공 하이라이트 (녹색)
   - 과세 → 경고 하이라이트 (노란색)
   - 계산 상세 내역 표시
   - 경고 메시지 (있는 경우)
```

### 3. 초기화 플로우
```
1. "초기화" 버튼 클릭
   ↓
2. handleReset() 실행
   - formData를 초기값으로 리셋
   - result를 null로 설정
   - showResults를 false로 설정
   - holdingPeriod를 null로 설정
   - errors를 빈 객체로 설정
   ↓
3. 폼이 초기 상태로 돌아감
```

## 문제 해결 (Troubleshooting)

### 문제 1: 보유기간이 표시되지 않음
**원인**: 날짜 입력 형식 오류
**해결**:
```javascript
// 날짜 형식 확인: YYYY-MM-DD
console.log(formData.acquisitionDate); // "2024-01-15"
console.log(formData.transferDate);    // "2024-06-20"
```

### 문제 2: 계산 결과가 0원으로 나옴
**원인**: 숫자 파싱 오류
**해결**:
```javascript
// 천 단위 구분 기호 제거 확인
const price = parseNumber(formData.transferPrice); // 쉼표 제거
console.log(price); // 800000000 (숫자)
```

### 문제 3: 스타일이 적용되지 않음
**원인**: CSS 파일 임포트 누락
**해결**:
```javascript
// CapitalGainsTaxForm.jsx 상단에 추가
import './CapitalGainsTaxForm.css';
```

### 문제 4: 모바일에서 레이아웃 깨짐
**원인**: 뷰포트 메타 태그 누락
**해결**:
```html
<!-- index.html에 추가 -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
