## 2. 장기보유특별공제 개요

### 2.1 공제의 목적
**목적**: 장기간 보유한 자산에 대해 양도소득세 부담을 경감

**적용 대상**:
- 부동산 (토지, 건물)
- 주택 (1세대1주택 우대)

**적용 시점**:
- 양도차익에서 공제 (세율 적용 전)

### 2.2 기본 원칙
1. **보유기간 3년 이상**: 공제 적용 (3년 미만은 0%)
2. **보유기간이 길수록**: 공제율 증가
3. **1세대1주택 우대**: 일반 부동산 대비 2배 공제율

## 4. 보유기간 계산

### 4.1 기본 보유기간 계산
```javascript
/**
 * 보유기간 계산 (년 단위, 소수점 버림)
 * @param {Date} acquisitionDate - 취득일
 * @param {Date} transferDate - 양도일
 * @returns {number} 보유년수 (정수)
 */
function calculateHoldingYears(acquisitionDate, transferDate) {
  const diffInMs = transferDate - acquisitionDate;
  const diffInDays = diffInMs / (1000 * 60 * 60 * 24);
  const years = diffInDays / 365;

  // 년 단위로 내림 (3.9년 → 3년)
  return Math.floor(years);
}
```

**예시**:
```javascript
// 2020-01-01 취득 → 2024-10-01 양도
// 보유기간: 4년 9개월 → 4년으로 계산
calculateHoldingYears(
  new Date('2020-01-01'),
  new Date('2024-10-01')
) // = 4
```

### 4.2 거주기간 합산 (1세대1주택만)

**규정**: 1세대1주택의 경우 실제 거주한 기간을 보유기간에 합산 가능

**합산 방법**:
```javascript
/**
 * 거주기간 합산 (1세대1주택만)
 * @param {number} holdingYears - 보유년수
 * @param {number} residenceYears - 거주년수
 * @param {boolean} is1House - 1세대1주택 여부
 * @returns {number} 총 기간 (보유 + 거주)
 */
function calculateTotalYears(holdingYears, residenceYears, is1House) {
  if (!is1House) {
    // 1세대1주택이 아니면 거주기간 합산 안 됨
    return holdingYears;
  }

  // 거주기간이 없으면 보유기간만
  if (!residenceYears || residenceYears <= 0) {
    return holdingYears;
  }

  // 거주기간 합산
  const totalYears = holdingYears + residenceYears;

  return totalYears;
}
```

**예시**:
```javascript
// 보유 5년, 거주 3년 (1세대1주택)
calculateTotalYears(5, 3, true) // = 8년

// 보유 5년, 거주 3년 (다주택자)
calculateTotalYears(5, 3, false) // = 5년 (거주기간 무시)
```

**주의사항**:
- 거주기간은 보유기간을 초과할 수 없음
- 실제 주민등록상 거주 여부로 판단
- 최대 합산 기간 제한 없음 (15년 이상도 가능)

## 5. 공제액 계산 로직

### 5.1 메인 계산 함수
```javascript
/**
 * 장기보유특별공제 계산
 * @param {Object} params
 * @returns {Object} 공제 계산 결과
 */
function calculateLongTermHoldingDeduction(params) {
  const {
    capitalGain,          // 양도차익
    holdingYears,         // 보유년수
    residenceYears = 0,   // 거주년수 (선택)
    houseCount,           // 주택 수
  } = params;

  // 1세대1주택 여부 판단
  const is1House = houseCount === 1;

  // 총 기간 계산 (보유 + 거주)
  const totalYears = calculateTotalYears(holdingYears, residenceYears, is1House);

  // 3년 미만 → 공제 불가
  if (totalYears < 3) {
    return {
      deductionRate: 0,
      deductionAmount: 0,
      totalYears,
      holdingYears,
      residenceYears: is1House ? residenceYears : 0,
      is1House,
      reason: '보유기간 3년 미만 (공제 불가)'
    };
  }

  // 공제율 결정
  const deductionRate = getDeductionRate(totalYears, is1House);

  // 공제액 계산
  const deductionAmount = Math.floor(capitalGain * deductionRate);

  return {
    deductionRate,
    deductionAmount,
    totalYears,
    holdingYears,
    residenceYears: is1House ? residenceYears : 0,
    is1House,
    reason: `${is1House ? '1세대1주택' : '일반 부동산'} ${totalYears}년 보유 공제`
  };
}
```

### 5.2 공제율 결정 함수
```javascript
/**
 * 보유년수에 따른 공제율 결정
 * @param {number} totalYears - 총 기간 (보유 + 거주)
 * @param {boolean} is1House - 1세대1주택 여부
 * @returns {number} 공제율 (0~0.80)
 */
function getDeductionRate(totalYears, is1House) {
  // 공제율 테이블
  const RATES_1HOUSE = [
    { years: 3, rate: 0.12 },
    { years: 4, rate: 0.16 },
    { years: 5, rate: 0.20 },
    { years: 6, rate: 0.24 },
    { years: 7, rate: 0.28 },
    { years: 8, rate: 0.32 },
    { years: 9, rate: 0.36 },
    { years: 10, rate: 0.40 },
    { years: 11, rate: 0.48 },
    { years: 12, rate: 0.56 },
    { years: 13, rate: 0.64 },
    { years: 14, rate: 0.72 },
    { years: 15, rate: 0.80 }
  ];

  const RATES_MULTI_HOUSE = [
    { years: 3, rate: 0.06 },
    { years: 4, rate: 0.08 },
    { years: 5, rate: 0.10 },
    { years: 6, rate: 0.12 },
    { years: 7, rate: 0.14 },
    { years: 8, rate: 0.16 },
    { years: 9, rate: 0.18 },
    { years: 10, rate: 0.20 },
    { years: 11, rate: 0.24 },
    { years: 12, rate: 0.28 },
    { years: 13, rate: 0.32 },
    { years: 14, rate: 0.36 },
    { years: 15, rate: 0.40 }
  ];

  // 공제율 테이블 선택
  const rates = is1House ? RATES_1HOUSE : RATES_MULTI_HOUSE;

  // 해당 년수의 공제율 찾기 (역순 탐색)
  let applicableRate = 0;
  for (let i = rates.length - 1; i >= 0; i--) {
    if (totalYears >= rates[i].years) {
      applicableRate = rates[i].rate;
      break;
    }
  }

  return applicableRate;
}
```

## 7. 엣지 케이스

### 7.1 거주기간이 보유기간보다 긴 경우
**케이스**: 입력 오류 또는 데이터 검증 누락
```javascript
Input:
{
  holdingYears: 3,
  residenceYears: 5,         // 보유기간보다 김
  houseCount: 1
}

처리:
// 거주기간은 보유기간을 초과할 수 없음
const validResidenceYears = Math.min(residenceYears, holdingYears);
const totalYears = holdingYears + validResidenceYears;
// 또는 에러 발생
throw new Error('거주기간은 보유기간을 초과할 수 없습니다');
```

// 공제율: 3년 기준 적용 (12% or 6%)
