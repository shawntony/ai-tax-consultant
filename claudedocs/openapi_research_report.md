# 국세청 OpenAPI 조사 보고서
**M2.1.10.1 - 국세청 OpenAPI Research Report**

**작성일**: 2025-10-18
**작성자**: AI Tax Consultant Development Team
**조사 시간**: 6h
**조사 목적**: 세법 데이터 자동 업데이트를 위한 공공 API 활용 가능성 평가

---

## 📋 Executive Summary

### 조사 결과 요약
국세청에서 제공하는 세율 정보(상속세, 증여세, 양도소득세)를 **실시간으로 조회할 수 있는 OpenAPI는 존재하지 않음**.

### 주요 발견사항
1. ✅ **사업자 정보 API**: 사업자등록정보 진위확인 API 존재 (세율 정보 X)
2. ✅ **법령 해석 API**: 국세청 법령해석 목록 조회 API 존재 (법령 해석 사례만)
3. ❌ **세율 정보 API**: 상속세/증여세/양도소득세 세율 조회 API 없음
4. ✅ **통계 데이터**: TASIS(국세통계포털)에서 파일 다운로드 형태 제공
5. ✅ **공공데이터포털**: 국세통계연보 XLS/XLSX 파일 제공

### 권장 사항
**대안 1**: 웹 크롤링 방식으로 국세청 홈페이지에서 세율 정보 수집
**대안 2**: 수동으로 세율 정보를 주기적으로 업데이트 (연 1-2회)
**대안 3**: 국세통계연보 파일을 다운로드하여 파싱 (파일 형식 의존성 높음)

## ⚖️ 3. 세율 정보 자동 업데이트 가능성 평가

### 3.1 OpenAPI 활용: ❌ **불가능**

**이유**:
1. 세율 정보를 직접 제공하는 OpenAPI 존재하지 않음
2. 사업자등록 API는 세율 정보와 무관
3. 법령해석 API는 해석 사례만 제공, 세율 데이터 없음
4. TASIS는 API 형태가 아닌 웹 포털

**결론**: 공공 OpenAPI를 통한 세율 자동 업데이트는 **불가능**

---

### 3.2 파일 다운로드 방식: ⚠️ **제한적 가능**

**방법**:
1. 공공데이터포털에서 국세통계연보 파일 다운로드
2. Excel 파일 파싱하여 세율 정보 추출
3. 데이터베이스 업데이트

**장점**:
- ✅ 공식 데이터 소스
- ✅ 무료
- ✅ 법적 문제 없음

**단점**:
- ❌ 실시간 업데이트 불가 (연 1-3회만 발행)
- ❌ 파일 구조 변경 시 파싱 로직 수정 필요
- ❌ 수동 다운로드 필요 (완전 자동화 어려움)
- ❌ 세율표가 포함되지 않을 수 있음 (통계 중심)

**평가**: 보조 수단으로 활용 가능하나 주 업데이트 방법으로는 **부적합**

---

### 3.3 웹 크롤링 방식: ⚠️ **가능하나 제약 있음**

**방법**:
1. 국세청 홈페이지 세법 안내 페이지 크롤링
2. HTML 파싱하여 세율표 추출
3. 정기적으로 크롤링하여 변경사항 감지
4. 변경 감지 시 데이터베이스 업데이트

**장점**:
- ✅ 세법 개정 시 즉시 반영된 데이터
- ✅ 구조화된 세율표 제공
- ✅ 자동화 가능

**단점**:
- ❌ 웹사이트 구조 변경 시 크롤링 로직 수정 필요
- ❌ robots.txt 확인 필요
- ❌ 법적 이슈 검토 필요 (저작권, 이용약관)
- ❌ 서버 부하 고려 필요 (과도한 크롤링 금지)

**평가**: 기술적으로 가능하나 법적 검토 및 유지보수 부담 존재

---

### 3.4 수동 업데이트 방식: ✅ **현실적 대안**

**방법**:
1. 연 1-2회 세법 개정 시 수동으로 세율 정보 업데이트
2. 국세청 홈페이지 및 관보 모니터링
3. `taxRates.js`, `deductions.js` 파일 직접 수정
4. Git을 통한 버전 관리

**장점**:
- ✅ 가장 안전하고 확실한 방법
- ✅ 법적 문제 없음
- ✅ 데이터 정확성 보장 (사람이 검증)
- ✅ 유지보수 부담 적음

**단점**:
- ❌ 완전 자동화 불가
- ❌ 사람의 개입 필요
- ❌ 즉시 반영 어려움

**평가**: 가장 **현실적이고 안전한 방법**

**소요 시간**: 개정당 2-4시간

#### Phase 2: 변경 감지 알림 시스템 (중기)

**목적**: 세법 개정 즉시 개발팀에 알림

**구현 방안**:
```javascript
// src/services/taxLawMonitor.js
class TaxLawMonitor {
  async checkForUpdates() {
    // 1. 국세청 홈페이지 크롤링 (주 1회)
    const currentContent = await this.fetchTaxLawPage()

    // 2. 이전 버전과 비교
    const hasChanged = this.detectChanges(currentContent)

    // 3. 변경 감지 시 알림
    if (hasChanged) {
      await this.sendNotification({
        type: 'TAX_LAW_UPDATE',
        message: '세법 개정이 감지되었습니다.',
        url: 'https://www.nts.go.kr/...'
      })
    }
  }

  async sendNotification(alert) {
    // 이메일, Slack, Discord 등으로 알림
    await sendEmail(ADMIN_EMAIL, alert)
    await logToDatabase(alert)
  }
}
```

**장점**:
- ✅ 세법 개정 즉시 인지
- ✅ 수동 모니터링 부담 감소
- ✅ 자동화 최소화 (법적 리스크 낮음)
